What is CRMF?

The Cyber Resilience Maturity Framework is a comprehensive GRC assessment tool developed as part of a Duke MEng Cybersecurity capstone project. It evaluates organisational cyber resilience across five pillars using a dynamic profiling system that filters and weights questions based on your specific sector, size, funding level, and technology environment.

Scoring Methodology

📋

Implementation

35% weight — how fully the control is deployed

🧪

Test Type

25% weight — how rigorously it has been tested

🎯

Coverage Scope

20% weight — how much of the environment it covers

📅

Last Reviewed

15% weight — how recently it was reviewed

💪

Stress Tested

5% weight — whether it has been pushed to failure
